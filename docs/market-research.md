# 市场调研报告：简历助手

> 版本: v1.0 | 日期: 2026-06-16 | 作者: Research Agent
> 调研范围: AI简历分析 / JD技能匹配 / 求职辅助工具 | 调研时间: 2026年6月

---

## 1. 执行摘要

**结论先行**：AI 简历分析 + JD 技能匹配这个赛道**需求真实且被充分验证**，但市场已从"蓝海"转入"红海早期"——开源侧有 **27.3k Stars 的 Resume-Matcher**，商业侧有**超百万用户的鹅来面**和**3000万用户的超级简历 WonderCV**，Claude Code Skill 生态内已有 **clawcv（超级简历出品，API 付费）**和 **resuml** 等 7+ 款直接竞品。

**核心机会不在"有没有人做"，而在"怎么做差异化"**：现有产品要么是云端 SaaS（隐私隐患），要么是 API-Key 付费墙（非真正开源），真正 **100% 本地运行 + 完全开源免费 + Claude Code Skill 形态**的产品尚未出现。这是本项目的唯一有效切入点。

### 3.2 用户痛点验证

通过搜索社区讨论（CSDN、少数派、Product Hunt 评论区），验证以下痛点确实存在：

1. **"投了 100 份简历，面试只有 2-3 个"** —— 简历与 JD 不匹配导致 ATS 初筛淘汰（高频讨论）
2. **"不知道自己和岗位差在哪里"** —— 缺乏技能差距的结构化分析（中频讨论）
3. **"改简历全靠猜"** —— 没有数据驱动的修改建议（高频讨论）
4. **"云端工具不敢上传真实简历"** —— 隐私顾虑（中频讨论，尤其国内用户）

### 3.3 本项目定位的用户价值

与现有多数产品不同，本项目的**核心价值主张**是：
- **本地运行**（100% 隐私） + **完全开源**（无 API Key 付费墙） + **技能差距 → 学习建议闭环**（不只是匹配评分）

基于搜索得到的社区讨论和产品数据，核心用户画像如下：

- **痛点等级**：高（缺乏就业市场信息，焦虑感强）

- **付费意愿**：低（学生预算有限），但免费工具 + GitHub Star 意愿高

### 画像 B：职场人（3-5 年经验）
- **年龄**：25-35 岁
- **行为**：主动或被动跳槽，想升级但不知道缺什么技能
- **痛点等级**：中高（信息不对称，缺少客观评估）
- **技术门槛**：如果非技术背景，Claude Code 安装使用门槛较高
- **付费意愿**：中等（有收入，但已习惯免费工具）

### 画像 C：技术类求职者（工程师/数据科学家）
- **年龄**：22-40 岁
- **行为**：经常刷 GitHub，习惯命令行工具，对 Claude Code 熟悉
- **痛点等级**：中（技术岗位 JD 技能要求明确，但数量多难以逐一对比）
- **技术门槛**：低（原生目标用户）
- **付费意愿**：中等偏低（乐于 Sponsor 开源项目）

## 7. 头号竞品深度分析：clawcv（超级简历）

### 7.1 基本信息
- **出品方**：北京超职科技有限公司（超级简历 WonderCV）
- **上线时间**：2026 年 4 月（v1.1.0）
- **产品形态**：npm 包 `clawcv`，通过 MCP Server 接入 Claude Code/OpenClaw/Cursor
- **定价**：普通用户 20次/天（需 API Key），会员 50次/天，终身会员 100次/天

### 7.2 优势
- 背靠超级简历 3000 万用户数据积累
- 中文生态最成熟的简历 AI 产品
- 功能最全：简历分析 + 岗位匹配 + 校招匹配 + PDF 导出 + AI 导师
- Claude Code Skill 生态内最早入局者之一

### 7.3 关键弱点
- **非真正开源**：代码开源但核心能力依赖云端 API（api.wondercv.com），本质是 SaaS 的 CLI 入口
- **配额限制严格**：免费版 20次/天远不够海投使用
- **隐私问题**：简历数据必然上传到超级简历服务器（API Key 绑定用户身份）
- **npm 周下载仅 52 次**：虽然产品功能强，但 Claude Code Skill 形态的用户渗透率极低
- **无技能成长追踪**：没有记忆文件/技能档案持久化

### 7.4 如果 clawcv 反击
- 最可能方向：**取消配额限制或大幅提高免费额度**（用资本碾压）
- 其次：开放更多本地化能力
- 但受限于其商业模式（SaaS 订阅 + 数据资产），**不可能做到 100% 本地运行**
