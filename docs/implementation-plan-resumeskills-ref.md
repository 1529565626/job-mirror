### C-1 修改内容

**文件：`skill/SKILL.md` — 工作流 2 步骤 6（resumeSuggestions 生成规范）**

现有 `suggestion` 字段是纯文本描述。升级为 Before/After 对比格式。

**格式规范变更**：

```
旧格式：
  suggestion: "建议补充量化数据来描述用户增长成果"

新格式：
  suggestion: {
    before: "参与用户增长项目，通过优化产品功能提升了用户留存",
    after: "主导用户留存优化项目，通过 A/B 测试定位关键流失节点，推动 7 日留存率从 45% 提升至 62%（+17pp）",
    formula: "[动词] [做了什么] [通过什么方式] [产生了什么可量化结果]",
    note: "量化数据为基于项目规模的合理估计，建议替换为实际数据"
  }
```

**量化注入规则**：当用户原文无数字时——
- 优先从上下文推断（如"负责XX产品"→可推断用户规模量级）
- 无法推断时，使用范围估计并标注 `[估计值，建议替换]`
- **绝不编造精确数字**

2. **操作意图优先**：含具体操作词（"提升"/"新增"/"删除"）优先于查看词（"看"/"查看"）
   - 例："Python 提升到精通" → 走工作流 4（修改技能），而非工作流 3（查看档案）
3. **未消歧时主动追问**：无法判定意图时，列出可能的工作流让用户选择
   - 例："帮我看一下" → 回复"你是想看'个人档案'还是'最新分析报告'？"

### G-1 修改内容

**文件：`skill/SKILL.md` — 新增「边界情况处理」章节 + 修改评分标准章节**

**新增章节：边界情况处理**

覆盖 7 类特殊场景及处理策略：

| 场景 | 识别条件 | 特殊处理 |
|------|---------|---------|
| **应届生** | yearsOfExperience = 0，education 含"本科/硕士"+ 毕业年份 ≥ 当前年 | 评分权重动态调整（见下方）；技能匹配扩展至课程+项目+实习 |
| **职业转行者** | profile.industry ≠ JD.industry 且匹配度 < 60% | 放宽技能语义匹配；允许跨类别映射；降低年限权重×0.3 |
| **高管/10年+** | yearsOfExperience ≥ 10 | JD 解析侧重战略词汇（P&L/团队规模/董事会/并购）；ATS 检查仍适用 |
| **就业空白期** | experiences 中存在 ≥ 6 个月的间隔 | 不扣分不主动提及；关注最近经历的 JD 相关性 |
| **多重JD版本** | 同一岗位 slug 已存在 | 追加 v2/v3 而非覆盖；新报告关联到新版 JD |
| **超大简历** | 简历文本 > 5000 字 | 提示"简历较长，建议截取核心近 5 年经历"，仍继续处理 |
| **纯英文简历** | 中文字符 < 5% | 技能对标时中英文自动映射；熟练度描述词使用英文映射表 |

**评分标准章节修改：动态权重**

在现有固定权重 `skillMatch × 0.5 + experienceMatch × 0.3 + educationMatch × 0.2` 基础上，增加场景检测后的权重调整：

```
检测到应届生场景：
  overallScore = skillMatch × 0.3 + experienceMatch × 0.2 + educationMatch × 0.5

检测到转行者场景：
  overallScore = skillMatch × 0.6 + experienceMatch × 0.1 + educationMatch × 0.3
  （降低经验权重，因为跨行业经验参考价值低；提高技能权重，因为这是唯一可控变量）

默认场景：保持现有公式不变
```

在报告的 `match` 对象中新增 `weightAdjustment` 字段记录是否触发了动态权重：
```json
{
  "match": {
    "overallScore": 72,
    "weightAdjustment": null,        // 默认 null = 标准权重
    "weightAdjustmentReason": null   // 触发时写入原因
  }
}
```
```
触发应届生场景时：
{
  "weightAdjustment": "fresh-graduate",
  "weightAdjustmentReason": "检测到应届生，教育权重提高至 0.5，经验权重降低至 0.2"
}
```
